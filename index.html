What Safer Choice Does

The project is designed as a connected software ecosystem where the mobile application, backend services and supported devices work together to provide safety-related functionality.

01 / MOBILE

Safety Application

A Flutter-based Android application provides the main interface for safety features, contacts, alerts and communication.

02 / ALERTS

Emergency Alerts

The application can communicate important safety events to trusted contacts through connected backend and notification services.

03 / ANALYSIS

Intelligent Analysis

The project explores audio and machine-learning based analysis that can be used as part of intelligent safety features.

04 / COMMUNICATION

Real-Time Communication

Mobile clients communicate with backend services to exchange application events, messages and notifications.

05 / WEARABLE

Wearable Integration

Bluetooth Low Energy technology is explored for communication between the mobile application and supported wearable devices.

06 / BACKEND

Cloud Infrastructure

Backend services provide APIs, application state, notification delivery and communication between connected components.

Software Architecture

The system is separated into multiple components so that mobile clients, backend services and connected devices can communicate through defined interfaces.

01

Mobile Client

Handles the user interface, application logic, permissions and communication with the backend.

02

Backend API

Provides application endpoints and processes requests between clients and cloud services.

03

Notification Layer

Delivers application events and safety notifications through push notification infrastructure.

04

Wearable Layer

Provides Bluetooth communication between compatible wearable devices and the mobile application.
