Software Features

Safer Choice is developed as a software platform with multiple application and backend components designed to communicate with each other in real time.

01 / MOBILE

Mobile Application

A Flutter-based mobile application provides the main user interface and connects users with the safety features implemented by the platform.

02 / COMMUNICATION

Real-Time Communication

The software architecture supports communication between users, devices and backend services for delivering safety notifications and events.

03 / INTELLIGENCE

Intelligent Analysis

The project explores machine-learning and signal analysis techniques that can be integrated into mobile safety applications.

04 / CLOUD

Cloud Backend

Backend services provide APIs, notification delivery, application state management and communication between the mobile application and cloud infrastructure.

05 / DEVICE

Wearable Integration

The project also explores integration between mobile applications and wearable devices using Bluetooth communication technologies.

06 / SECURITY

Secure Software Design

Application architecture focuses on secure communication, controlled access and responsible handling of application data.

Software Architecture

Safer Choice is designed as a multi-component software system where the mobile client, backend services and connected devices work together.

Mobile Client

The mobile application provides the user interface, manages application permissions and communicates with backend services.

Backend API

Backend services process requests, maintain application state and provide communication endpoints for clients.

Notification Layer

Push notification services allow the application to deliver important events and safety notifications.

Wearable Layer

Bluetooth communication allows supported wearable devices to exchange information with the mobile application.
